## Submission form

Check each answer against what you actually show, and put them in your own voice.

**Track:** confirm which one you applied to. I assumed Indie.

**Problem statement:** Build for Your World

**Public GitHub repository:** https://github.com/Sandgrouse/storyverse

**Project description**

> Storyverse is a command centre for one story told across many channels. Give it your scripts and art, and it builds a single master copy of your story world, splits the story so that each channel holds its own secret, and produces what each channel needs: character sheets, scene art, scripts and packages for coding agents. Change one fact and it finds every scene that breaks across every channel, proposes the smallest fix, and re-checks the whole story. I built it because I keep rebuilding the same characters in different tools for a game I'm making, and nothing keeps the story straight. The demo uses Anukili Ugama, an Igbo myth from where I come from.

**Describe your use of Meta products**

> Muse Spark 1.3 reads PDFs, text and images into a structured canon, plans the channels, runs the continuity ripple with structured output, rewrites scenes, re-checks the canon, and writes production material. Muse Image 1.0 draws character sheets and scene art, anchored on reference images and chained with previous_response_id to stay on-model. SAM 3.1 cuts characters out for transparent game assets. Muse Code wrote the application code from task specs, through pull requests. I used Claude Code to write those specs and design prototypes and to review the pull requests, and the repo records this.

**Why are Meta's models important to your solution?**

> The whole product depends on one model holding a complete story in context and reasoning about who may know what. Muse Spark's 1M-token context and multimodal input let it read raw material directly, with no retrieval system, and its structured output makes each fix safe to apply. Muse Image's anchoring is what makes one character sheet reusable, which was my original problem, and SAM 3.1 turns those sheets into usable assets.
